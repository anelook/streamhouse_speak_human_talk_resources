# Teaching Streamhouse to Speak Human — Resources

Resources for exploring how streaming data can be made queryable by people and AI agents using SQL, LLMs, and the Model Context Protocol (MCP).

## Start here

0. [What is Streamhouse?](https://developer.confluent.io/learn/streamhouse/) - Streamhouse explained
1. [Lightning Tables — Overview](https://docs.confluent.io/cloud/current/lightning-tables/overview.html) — How Kafka data becomes queryable through materialized tables.
2. [Real-Time Context Engine — Overview](https://docs.confluent.io/cloud/current/ai/real-time-context-engine/overview.html) — How AI agents access current Kafka data.
3. [Get Started with the Real-Time Context Engine](https://docs.confluent.io/cloud/current/ai/real-time-context-engine/get-started.html) — Setup walkthrough.
4. [Query Data Through MCP](https://docs.confluent.io/cloud/current/ai/real-time-context-engine/query-data.html) — Tools such as `listTopics`, `getMetadata`, and `queryData`.
5. [Lightning Table SQL Reference](https://docs.confluent.io/cloud/current/lightning-tables/query/sql-reference.html) — Supported SQL queries and restrictions.
6. [USGS Earthquake GeoJSON Feeds](https://earthquake.usgs.gov/earthquakes/feed/v1.0/geojson.php) — Public earthquake data used for the example.
